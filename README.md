# phytocure

![Phytocure](https://iili.io/Bbi82LJ.png)

DeSci infrastructure for medical cannabis built on Solana.

---

**Phytocure** is an open-access decentralized science protocol combining on-chain clinical prescription records, a verified global distributor network, AI-assisted cannabinoid analysis, and token-incentivized peer-reviewed research.

→ [phytocure.xyz](https://phytocure.xyz)
